## LoraC Language Reference v2.0

### Введение
LoraC — это стековый процедурный язык программирования. Компилятор написан на Python и генерирует ассемблер для LoraCore.
Главная особенность: полноценная поддержка стековых кадров, рекурсии и локальных областей видимости.

### Структура программы и Модули
Поддерживается модульная система. Файл может подключать другие файлы. Сборка происходит в единый бинарный файл.

```text
import "drivers/gpu.lc";
import "consts.lc";

const SCREEN_W = 480;
let global_counter = 0; // Глобальная переменная (в .data)

fn main() {
    // Точка входа
}
```

### Типы данных и Переменные
*   **Тип:** Единственный тип данных — 32-битное знаковое целое.
*   **Локальные переменные:** `let x = 10;`. Хранятся на **стеке** (относительно R14). Живут только внутри функции.
*   **Глобальные переменные:** Объявленные вне функций `let`. Хранятся в статической памяти (`.data`). Видны везде.
*   **Константы:** `const NAME = 123;`. Подставляются на этапе компиляции.

### Память
*   `mem[addr] = val;` — запись.
*   `let x = mem[addr];` — чтение.
*   Адрес может быть любым сложным выражением.

### Функции
*   **Объявление:** `fn name(p1, p2) { ... }`
*   **Вызов:** Аргументы пушатся на стек.
*   **Возврат:** `return expr;` (результат в R0) или неявный возврат (void) в конце блока.

### Управляющие конструкции
*   `if (cond) { ... } else { ... }`
*   `while (cond) { ... }`
    *   `break;` — выход из цикла.
*   `halt;` — полная остановка CPU.
*   `wait(cycles);` — ожидание (пауза).

### Операторы
*   Арифметика: `+`, `-`, `*`, `/`, `%`
*   Битовые: `&`, `|`, `^`, `~` (NOT), `<<`, `>>`
*   Логические: `&&`, `||`, `!` (NOT)
*   Сравнение: `==`, `!=`, `>`, `<`, `>=`, `<=`

### Пример (Актуальный)

```text
import "sys/video.lc";

fn factorial(n) {
    if (n <= 1) {
        return 1;
    }
    // Рекурсия работает благодаря стеку
    return n * factorial(n - 1);
}

fn main() {
    let result = factorial(5);

    if (result == 120) {
        gpu_print(10, 10, "Success", 0xFF00FF00);
    } else {
        gpu_print(10, 10, "Fail", 0xFFFF0000);
    }

    while(1) {
        wait(100);
    }
}
```
