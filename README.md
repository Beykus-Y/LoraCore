# AI Assistant Mod для Minecraft (Исходный код)

## Обзор
Этот мод добавляет в Minecraft ИИ-помощника, который отвечает на вопросы игроков, генерирует уникальные названия и описания для структур, а также создает личности для жителей деревень. Также реализована базовая система квестов.

## Основные возможности
- **Ответы от ИИ:** Игроки могут задавать вопросы через команду `/ask`, получая ответы от OpenAI API.
- **Динамические названия структур:** Структуры в игре получают уникальные названия и описания, основанные на их типе и биоме.
- **Личности жителей:** Каждый житель имеет уникальное имя и характер, сгенерированные ИИ.
- **Система квестов:** Базовая реализация квестов с интерфейсом журнала заданий.
- **Пользовательский интерфейс:** Добавлены GUI для диалогов с жителями и журнала квестов, а также кастомные привязки клавиш.

## Установка и сборка
1. **Зависимости:**
    - Fabric Loader (`>=0.15.10`)
    - Fabric API
    - Cardinal Components (`cardinal-components-base`, `cardinal-components-entity`)
    - Дополнительно: ModMenu и Cloth Config для настроек
2. **Настройка API:**
    - Укажите ваш ключ OpenAI API в файле конфигурации `aiassist.json` в папке `config`.
3. **Сборка:**
    - Убедитесь, что у вас установлен JDK 21.
    - Выполните команду `./gradlew build` в корневой папке проекта для сборки мода.

## Использование
- **Задавайте вопросы:** Используйте `/ask <вопрос>` для общения с ИИ.
- **Диалоги с жителями:** Присядьте (Shift) и кликните правой кнопкой мыши по жителю, чтобы начать диалог.
- **Журнал квестов:** Нажмите клавишу `J` (по умолчанию) для открытия журнала заданий.

## Структура кода
- **Клиентская часть (`src/client/java/com/aiassist`):** Логика интерфейсов, привязки клавиш и миксины для клиента.
- **Основная часть (`src/main/java/com/aiassist`):** Серверная логика, интеграция с ИИ, компоненты и сетевое взаимодействие.
- **Компоненты:** Используются Cardinal Components для хранения данных о жителях (`VillagerDataComponent`) и игроках (`PlayerDialogueComponent`, `PlayerQuestComponent`).
- **Сеть:** Кастомные пакеты (`ModNetworking`) для синхронизации данных между клиентом и сервером.
- **Сервисы:** `AiService` для работы с OpenAI API, `RecipeService` для поиска рецептов.

## Заглушки и задачи для доработки
- **Генерация квестов:** Реализовать систему генерации квестов с помощью ИИ вместо заглушки `createDebugQuest`.
- **Интеграция рецептов:** Доработать `RecipeService`, чтобы ИИ предоставлял точные рецепты в ответах.
- **Улучшение ошибок:** Добавить обработку исключений для API и парсинга JSON.
- **Локализация:** Внедрить поддержку многоязычности через файлы локализации.
- **Тестирование:** Провести полное тестирование всех функций мода.

# AI Assistant Mod

## Описание
AI Assistant Mod добавляет в Minecraft умного помощника, который отвечает на ваши вопросы, генерирует уникальные названия для структур и создает личности для жителей. Этот мод делает игру более интерактивной и увлекательной.

## Возможности
- **ИИ-помощник:** Задавайте вопросы с помощью команды `/ask <вопрос>` и получайте полезные ответы.
- **Уникальные структуры:** Исследуйте мир и находите структуры с названиями и описаниями, созданными ИИ.
- **Жители с характерами:** Взаимодействуйте с жителями, у которых есть свои имена и личности.
- **Квесты:** Выполняйте задания, чтобы получать награды (пока доступен только тестовый квест).

## Установка
1. **Требования:**
    - Fabric Loader (`>=0.15.10`)
    - Fabric API
    - Minecraft версии `1.20.6`
2. **Скачивание:** Загрузите `.jar` файл мода из раздела релизов.
3. **Установка:** Поместите файл в папку `mods` вашего Minecraft.
4. **Настройка:** Укажите ключ OpenAI API в файле `config/aiassist.json`.

## Использование
- **Вопросы ИИ:** Введите `/ask <вопрос>` в чате, чтобы получить ответ.
- **Диалог с жителями:** Присядьте (Shift) и кликните правой кнопкой мыши по жителю.
- **Журнал квестов:** Нажмите `J` (по умолчанию), чтобы открыть список заданий.

## Конфигурация
- **API Key:** Укажите ваш ключ OpenAI в `aiassist.json`.
- **Модель ИИ:** Выберите модель ИИ (по умолчанию `gpt-4o`) в настройках мода через ModMenu (если установлен).

## Известные проблемы
- **Квесты:** Пока доступен только тестовый квест "Просьба фермера". Полноценная система в разработке.
- **Рецепты:** ИИ не всегда точно отвечает на вопросы о крафте. Функция дорабатывается.
