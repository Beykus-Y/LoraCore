## Обзор

**LoraCore** — это инновационный мод для Minecraft, который обогащает игровой мир, интегрируя продвинутого ИИ-помощника. Он не просто отвечает на ваши вопросы; LoraCore создает динамически генерируемые названия для структур, наделяет жителей деревень уникальными личностями и предлагает базовую, но расширяемую систему квестов, делая каждый игровой сеанс более интерактивным и уникальным.

## Основные возможности LoraCore

*   **Интеллектуальный AI-помощник:** Задавайте любые вопросы о Minecraft прямо в чате через команду `/ask <ваш_вопрос>`. LoraCore использует OpenAI API для предоставления полезных, контекстуально релевантных ответов. Также ИИ способен консультировать по игровым рецептам, используя актуальные данные из игры.
*   **Динамические названия структур:** Исследуйте мир и открывайте новые структуры, которые автоматически получают уникальные названия и описания, сгенерированные ИИ на основе их типа и биома. Это добавляет элемент открытия и погружения в окружающий мир.
*   **Жители с личностями:** Каждый житель деревни теперь обладает уникальным именем и яркой индивидуальностью, сгенерированной ИИ. Это делает взаимодействие с ними более глубоким и непредсказуемым.
*   **Система квестов:** Взаимодействуйте с жителями, чтобы принимать и выполнять простые квесты. Задания динамически генерируются ИИ, предлагая вам найти и принести определенные предметы в обмен на уникальные награды.
*   **Пользовательский интерфейс:** Интуитивно понятные графические интерфейсы (GUI) для удобного общения с жителями и эффективного управления квестами (специальный журнал заданий).
*   **Настраиваемость:** Полная поддержка ModMenu позволяет легко настраивать параметры API-ключа, URL и выбора модели ИИ прямо в игре.
*   **Многоязычность:** LoraCore поддерживает несколько языков, обеспечивая тонкую настройку ответов ИИ в зависимости от выбранного игроком языка.

## Установка и сборка

### 1. Зависимости

Для корректной работы LoraCore необходимы следующие зависимости:

*   **Fabric Loader:** `fabricloader:>=0.15.10`
*   **Minecraft:** `~1.20.6`
*   **Java:** `>=21`
*   **Fabric API:** `fabric-api:*`
*   **Cardinal Components API:** `cardinal-components-base:*`, `cardinal-components-entity:*` (версия `6.0.0` или выше)
*   **ModMenu:** `modmenu:*` (рекомендуется для настройки)
*   **Cloth Config API:** `cloth-config-fabric:*` (необходим для ModMenu)

### 2. Установка (для игроков)

1.  Установите Fabric Loader для вашей версии Minecraft (1.20.6).
2.  Скачайте `.jar` файл **LoraCore** из раздела [релизов](https://github.com/Beykus-Y/LoraCore/releases).
3.  Поместите скачанный `.jar` файл в папку `mods` вашего Minecraft клиента.
4.  **Настройте API:**
   *   Запустите Minecraft.
   *   В главном меню перейдите в "Mods" (Моды) -> "LoraCore" -> "Config" (Настройки).
   *   Введите ваш **ключ OpenAI API** в соответствующее поле. Вы также можете изменить URL API или выбрать другую модель ИИ.
   *   Альтернативно, вы можете вручную отредактировать файл `loracore.json` в папке `config` вашего Minecraft-клиента.

### 3. Сборка (для разработчиков)

1.  Убедитесь, что у вас установлен **JDK 21**.
2.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/Beykus-Y/LoraCore.git
    cd LoraCore
    ```
3.  Выполните команду для сборки мода:
    ```bash
    ./gradlew build
    ```
    Готовый `.jar` файл будет находиться в папке `build/libs/`.

## Использование

*   **Задавайте вопросы AI:** В чате используйте команду `/ask <ваш_вопрос>`. Например: `/ask Как скрафтить кирку?`
*   **Диалог с жителями:** Присядьте (Shift) и кликните правой кнопкой мыши по жителю, чтобы начать диалог. Вы сможете общаться с ним, узнавать его личность и, возможно, получать квесты.
*   **Журнал заданий:** Нажмите клавишу `J` (по умолчанию) для открытия журнала активных заданий.

## Конфигурация

LoraCore полностью настраивается через ModMenu. Откройте меню модов, выберите "LoraCore" и нажмите кнопку "Config".

Доступные настройки:

*   **API URL:** Базовый URL для запросов к OpenAI API (по умолчанию: `https://api.openai.com/v1`).
*   **API Key:** Ваш секретный ключ для доступа к OpenAI API. **Обязательно для использования функций ИИ.**
*   **Model ID:** Идентификатор модели ИИ, которая будет использоваться для генерации ответов (по умолчанию: `gpt-4o`). Вы можете нажать кнопку "Получить/обновить список моделей", чтобы загрузить список доступных моделей с сервера OpenAI и выбрать из них.

## Технические детали

*   **Архитектура:** LoraCore разработан на базе Fabric и следует современным практикам разработки модов для Minecraft.
*   **Компоненты:** Для хранения данных о жителях (`loracore:villager_data`) и игроках (`loracore:player_dialogue`, `loracore:player_quest`) используются Cardinal Components API, что обеспечивает гибкость и расширяемость.
*   **Сетевое взаимодействие:** Реализованы кастомные пакеты (`com.loracore.network`) для синхронизации данных между клиентом и сервером (например, для запросов к ИИ, обмена сообщениями в диалогах, принятия/завершения квестов).
*   **Виртуальный компьютер планшета:** Система планшета реализует гибридную архитектуру с двумя режимами работы:
    *   **Lua-режим:** Используется для восстановления системы и выполнения простых скриптов. При отсутствии Java-ядра автоматически загружается скрипт восстановления `/os/recovery.lua` из ресурсов мода.
    *   **Java-режим:** Полноценная операционная система с загружаемым ядром. Планшет ищет файл `/boot/kernel.jar` в своей виртуальной файловой системе (VFS). При обнаружении загружает его как основное ядро системы.
    *   **Процесс загрузки:** Java-ядро выполняет роль "супервизора", проводя системные проверки и запуская основной пользовательский shell (`/bin/shell.lua`). Рендеринг экрана загрузки происходит на клиенте через `IKernelGraphics`, а после перехода в рабочий режим управление отрисовкой передается Lua-скриптам через серверную систему GPU-команд.
*   **Сервисы:**
   *   `AiService`: Основной сервис для взаимодействия с OpenAI API, обработки запросов, генерации личностей, названий структур и квестов.
   *   `RecipeService`: Вспомогательный сервис для поиска и форматирования внутриигровых рецептов для передачи ИИ.
*   **Миксины:** Используются для перехвата и изменения поведения ванильных классов (например, `VillagerEntity`) как на клиенте, так и на сервере, через конфигурации `loracore.mixins.json` и `loracore.client.mixins.json`.

## Текущее состояние и дальнейшие планы

*   **Система квестов:** Базовая динамическая генерация квестов реализована, но ее разнообразие и сложность будут постоянно улучшаться в будущих обновлениях.
*   **Интеграция рецептов:** ИИ уже использует данные о рецептов, но точность его ответов может варьироваться. Функция находится в стадии доработки для более надежного и точного предоставления информации.
*   **Обработка ошибок API:** Улучшена обработка ошибок при взаимодействии с API, но работа над более робастной обработкой всех возможных исключений продолжается.
*   **Тестирование:** Проводится постоянное тестирование для обеспечения стабильности и выявления возможных проблем.
