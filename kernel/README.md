# LoraCore OS Kernel

Этот модуль содержит полноценное ядро операционной системы LoraCore OS, написанное на Java.

## Возможности

- **Графический рабочий стол** в стиле планшета
- **Поддержка приложений** (.lua и .jar)
- **Система навигации** с кнопкой "Домой"
- **Безопасный API** для приложений
- **Управление состоянием** системы

## Структура проекта

```
│   └── util/                  # Утилиты
```

## Сборка

### Основное ядро

```bash
./gradlew build
```

Результат: `build/libs/kernel-1.3.0.jar`

## Установка

1. Скопируйте `kernel-1.3.0.jar` в `/boot/kernel.jar` в виртуальной файловой системе

## Разработка приложений

### Создание Java-приложения

1. Создайте класс, реализующий `IApplication`:

```java
public class MyApp implements IApplication {
    @Override
    public void onLoad(IApplicationApi api) {
        // Инициализация приложения
    }
    
    @Override
    public void onRender(IKernelGraphics g, int mouseX, int mouseY, float delta) {
        // Отрисовка интерфейса
    }
    
    @Override
    public void onEvent(KernelEvent event) {
        // Обработка событий
    }
    
    @Override
    public void onClose() {
        // Очистка ресурсов
    }
}
```

2. Создайте манифест `META-INF/MANIFEST.MF`:

```
Manifest-Version: 1.0
App-Main-Class: com.example.MyApp
```

3. Упакуйте в JAR-файл и поместите в `/home/user/apps/`

### API для приложений

Приложения получают доступ к безопасному API через `IApplicationApi`:

- **`getVfs()`** - доступ к файловой системе
- **`getGraphics()`** - графический API
- **`askAI(String prompt)`** - запрос к ИИ
- **`getScreenSize()`** - размер экрана
- **`runLuaScript(String path)`** - запуск Lua-скриптов

## Архитектура

### Управление приложениями

- `WindowManager` управляет активными приложениями
- Поддерживает как Lua-скрипты, так и Java-приложения
- Автоматическая загрузка классов из JAR-файлов

### Система событий

- События передаются от ядра к активному приложению
- Поддержка клавиатуры, мыши и других событий ввода
- Pattern matching для обработки событий

### Безопасность

- Приложения работают в изолированном окружении
- Ограниченный API для предотвращения вредоносного кода
- Автоматическая очистка ресурсов

## Ограничения

### Размер файлов

- JAR-файлы ограничены размером ~22KB (30000 символов в base64)
- Большие файлы будут обрезаны с предупреждением в логах

### Совместимость

- Приложения должны реализовывать интерфейс `IApplication`
- Манифест должен содержать `App-Main-Class`
- Поддерживаются только Java 21+ приложения
