# LoraOS - Структура проекта

## Обзор

LoraOS - это современная операционная система для планшета в игре Minecraft, реализованная на Java. Система построена по модульному принципу с четким разделением ответственности.

## Архитектура

```
com.lora.tabletos/
├── LoraOSKernel.java              # Главная точка входа
├── core/                          # Основные компоненты системы
│   ├── LoraOSKernel.java         # Основное ядро системы
│   └── SystemIntegrityManager.java # Проверка целостности системы
├── state/                         # Управление состояниями
│   ├── KernelState.java          # Enum состояний ядра
│   └── StateManager.java         # Менеджер переходов состояний
├── ui/                           # Пользовательский интерфейс
│   ├── desktop/                  # Рабочий стол
│   │   ├── Desktop.java          # Управление рабочим столом
│   │   └── DesktopIcon.java      # Иконки приложений
│   ├── window/                   # Управление окнами
│   │   └── WindowManager.java    # Менеджер окон
│   ├── navigation/               # Навигация
│   │   └── NavigationBar.java    # Навигационная панель
│   └── renderer/                 # Рендереры
│       └── BootScreenRenderer.java # Рендерер экрана загрузки
└── util/                         # Утилиты
    ├── ColorUtils.java           # Утилиты для работы с цветами
    └── GraphicsUtils.java        # Утилиты для работы с графикой
```

## Модули

### Core (Основные компоненты)

**LoraOSKernel** - главное ядро системы, реализующее интерфейс `IKernel`. Управляет жизненным циклом системы, координирует работу всех компонентов.

**SystemIntegrityManager** - проверяет и восстанавливает целостность файловой системы, создает необходимые директории.

### State (Управление состояниями)

**KernelState** - enum, определяющий все возможные состояния системы:
- `BOOTING` - начальная загрузка
- `CHECKING_SYSTEM` - проверка системы
- `INITIALIZING_UI` - инициализация UI
- `RUNNING` - нормальная работа
- `BOOT_FAILED` - сбой загрузки
- `KERNEL_PANIC` - критическая ошибка

**StateManager** - управляет переходами между состояниями, обеспечивает потокобезопасность.

### UI (Пользовательский интерфейс)

#### Desktop
**Desktop** - управляет рабочим столом, загружает и отображает иконки приложений.

**DesktopIcon** - представляет иконку приложения на рабочем столе.

#### Window
**WindowManager** - управляет окнами приложений (пока в разработке).

#### Navigation
**NavigationBar** - навигационная панель внизу экрана.

#### Renderer
**BootScreenRenderer** - рендерер экрана загрузки с градиентным фоном и анимированным индикатором.

### Util (Утилиты)

**ColorUtils** - утилиты для работы с цветами (интерполяция, прозрачность).

**GraphicsUtils** - утилиты для работы с графикой (градиенты, центрирование текста).

## Принципы проектирования

1. **Модульность** - каждый модуль имеет четко определенную ответственность
2. **Разделение ответственности** - UI отделен от бизнес-логики
3. **Состояние** - управление состоянием централизовано
4. **Утилиты** - общие функции вынесены в отдельные утилиты
5. **Документация** - каждый класс и метод документирован

## Использование

Главная точка входа - `com.lora.tabletos.LoraOSKernel`. Этот класс делегирует все вызовы к основному ядру в пакете `core`.

```java
// Создание экземпляра ядра
LoraOSKernel kernel = new LoraOSKernel();

// Загрузка ядра
kernel.onBoot(api);

// Основной цикл
kernel.onTick();
kernel.onRender(mouseX, mouseY, delta);
```

## Расширение

Для добавления новых компонентов:

1. **UI компоненты** - добавляйте в соответствующий пакет в `ui/`
2. **Утилиты** - добавляйте в `util/`
3. **Состояния** - расширяйте `KernelState` и `StateManager`
4. **Основная логика** - добавляйте в `core/`

## Совместимость

Система полностью совместима с существующим API LoraCore и не требует изменений в других частях мода.
